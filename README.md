QQBotAgent 6.0.0

QQ 聊天机器人。对接官方 QQBot API，模型走 OpenAI 兼容接口。无插件、无常驻提示词，对话按组压缩并保存在本地。

> [!CAUTION]
> **关闭网页并不能停止服务！** 直接关掉浏览器里的 WebUI 页面（或关掉整个浏览器），后台服务与机器人**仍然在运行**。只有以下两种方式会真正停止服务：
> 1. 在 WebUI 页面上点击红色的 **「一键停止服务」** 按钮；
> 2. 命令行执行 `python main.py --stop`。
>
> 想确认服务是否还在跑，可随时访问 <http://127.0.0.1:8000> 重新打开页面。

## 怎么用

要求：Windows，Python 3.9 或更高。

双击 `QQBotAgent-6.0\start.bat`。启动器会先直接运行主程序：能跑就直接启动并自动打开 `http://127.0.0.1:8000`；跑不动才检查缺了哪些运行库，逐项列出后询问是否安装（输入 1 安装，清华镜像、失败转官方 PyPI；输入 0 退出，不会擅自安装）。

在网页里填 QQ 机器人的 AppID、AppSecret 和大模型 API Key，点「启动机器人」。换模型时点「获取模型列表」，在「选择模型」下拉框选定后点「应用」即可生效。

## 技术说明

单文件主程序。前端内联在 `main.py` 里，复制一个文件就能跑。源码在 `web/index.html` 里改，执行 `python build_web.py` 写回。

存储用 SQLite，WAL 模式。三张表：`sessions` 存元数据，`messages` 按条追加消息，`archive` 存被压缩掉的原文。表结构用 `PRAGMA user_version` 逐级升级。

上下文分三层：最近两轮原文、结构化记忆 JSON、归档关键词召回。超出阈值时后台抽取事实写进 `memory.json`，被覆盖的原文进 `archive`，需要时按关键词召回几条，不进常规上下文。归档检索是关键词匹配，不是语义检索。

删除即覆写（`secure_delete`），配合 VACUUM，删掉的内容不会残留在数据库文件里。

消息处理按会话串行、全局并发受限，模型调用失败按 429、5xx、超时退避重试，鉴权错误直接抛。网关重连会对 msg_id 去重。

## 数据

```
data/config.json        配置，凭证经 DPAPI 加密
data/sessions.db        会话与归档
data/token_usage.json   token 统计，保留 30 天
data/app.log            运行日志，自动轮转
aux_data/               辅助机器人的配置与上下文
```

`data/` 和 `aux_data/` 不进版本库。

## 安全

API Key 和 AppSecret 用 Windows DPAPI 加密存储，界面只显示掩码。

Web 界面只绑 `127.0.0.1`，非本机请求返回 403，并做 Host 白名单和 Origin 比对。

日志过滤器对密钥打码，带参日志同样处理。

DPAPI 只能保证文件被复制走后无法解密，挡不住以当前用户身份运行的代码。

## 容器

```bash
docker build -t qqbotagent .
docker run -d -p 127.0.0.1:8000:8000 -v ./data:/app/data qqbotagent
```

端口映射写 `127.0.0.1:8000:8000`。接口只放行本机 Host，映射到公网地址会被拒绝。
