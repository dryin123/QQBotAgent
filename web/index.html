当前组累计 token 超过此值即触发压缩。
实际触发阈值取「压缩上限」与「窗口 60%」的较小值。填 0 表示不按窗口收敛。接口不返回窗口大小，需按模型手填。
压缩掉和翻篇的原文存入本地归档，按当前消息关键词召回。归档不进常驻上下文，不占 token。
超出丢最旧的，填 0 表示不限制。命令行可查看与删除：--archive-list / --archive-search / --archive-purge。

自动删除更早组的历史压缩文件，当前组永不删。
